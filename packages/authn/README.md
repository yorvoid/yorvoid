# yorvoid/authn

YorvoID's authentication: sessions, one-time tokens, setup and recovery codes, step-up and throttling. Part of [YorvoID](https://github.com/yorvoid/yorvoid), identity and access management for PHP.

```bash
composer require yorvoid/authn
```

Applications usually install [`yorvoid/symfony`](https://github.com/yorvoid/yorvoid/tree/main/packages/symfony), or [`yorvoid/passkeys`](https://github.com/yorvoid/yorvoid/tree/main/packages/passkeys) without a framework, which bring this package along. Read [Sessions](https://github.com/yorvoid/yorvoid/blob/main/docs/concepts/sessions.md), and [the rest of the documentation](https://github.com/yorvoid/yorvoid/tree/main/docs).
