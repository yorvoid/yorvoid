# yorvoid/passkeys

YorvoID's passkeys: WebAuthn registration and sign-in, user-verification policy, and passkey management. Part of [YorvoID](https://github.com/yorvoid/yorvoid), identity and access management for PHP.

```bash
composer require yorvoid/passkeys
```

This is where an application without a framework starts; with Symfony, install [`yorvoid/symfony`](https://github.com/yorvoid/yorvoid/tree/main/packages/symfony) instead. Read [Passkeys in any PHP application](https://github.com/yorvoid/yorvoid/blob/main/docs/tutorials/plain-php.md), and [the rest of the documentation](https://github.com/yorvoid/yorvoid/tree/main/docs).
