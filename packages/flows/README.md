# yorvoid/flows

YorvoID's flows: sign-in, recovery, enrolment and other journeys as server-side steps that applications insert into, replace or remove, rendered by templates or the browser client. Part of [YorvoID](https://github.com/yorvoid/yorvoid), identity and access management for PHP.

```bash
composer require yorvoid/flows
```

Applications usually install [`yorvoid/symfony`](https://github.com/yorvoid/yorvoid/tree/main/packages/symfony), or [`yorvoid/passkeys`](https://github.com/yorvoid/yorvoid/tree/main/packages/passkeys) without a framework, which bring this package along. Read [Flows](https://github.com/yorvoid/yorvoid/blob/main/docs/concepts/flows.md), and [the rest of the documentation](https://github.com/yorvoid/yorvoid/tree/main/docs).
