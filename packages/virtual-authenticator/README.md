# yorvoid/virtual-authenticator

YorvoID's virtual authenticator: a software WebAuthn authenticator for tests that answers registration and sign-in options as a browser would, and misbehaves on request. Part of [YorvoID](https://github.com/yorvoid/yorvoid), identity and access management for PHP.

```bash
composer require --dev yorvoid/virtual-authenticator
```

For tests only, so a development dependency. Read [The virtual authenticator](https://github.com/yorvoid/yorvoid/blob/main/docs/concepts/testing.md#the-virtual-authenticator), and [the rest of the documentation](https://github.com/yorvoid/yorvoid/tree/main/docs).
